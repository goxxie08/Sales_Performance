
Sales Performance Dashboard Analysis

Project Overview

This project presents a Sales Performance Analysis Dashboard developed using Power BI. The dashboard provides insights into sales performance, profit trends, customer segments, product categories, and regional sales distribution. It helps stakeholders monitor key business metrics and make data-driven decisions.

Objectives

* Analyze overall sales and profit performance.
* Identify top-performing regions and product categories.
* Understand customer segment contributions.
* Track sales trends over time.
* Visualize sales distribution using interactive charts.

Tools Used

* Power BI– Data visualization and dashboard creation
* CSV Dataset – Sales transaction data

Key Performance Indicators (KPIs)

* Total Sales
* Total Profit
* Total Orders
* Average Sales

Visualizations Used

1. Bar Chart

Purpose:Compare sales across regions.

Question:Which region has the highest sales?

2. Column Chart

Purpose:Compare sales across product categories.

Question: Which category generates the highest sales?

3. Line Chart

Purpose:Analyze sales trends over time.

Question:How do sales vary month by month?

4. Pie Chart

Purpose:Show sales contribution by customer segment.

Question:What percentage of sales comes from each customer segment?

5. Donut Chart

Purpose:Display category-wise sales distribution.

Question:What is the sales share of each category?

6. Scatter Chart

Purpose: Analyze the relationship between sales and profit.

Question: Is there a correlation between sales and profit?

7. Tree Map

Purpose: Visualize sales contribution by category and sub-category.

Question: Which categories and sub-categories contribute the most sales?

Dashboard Features

* Interactive filters and slicers
* KPI summary cards
* Sales trend analysis
* Regional performance comparison
* Customer segment analysis
* Product category insights

Conclusion

The dashboard provides a comprehensive view of sales performance, helping users identify trends, monitor key metrics, and understand factors contributing to business growth. Power BI's interactive visualizations make it easier to explore and interpret sales data effectively.
